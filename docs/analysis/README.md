# Published Analysis

This directory contains compact result artifacts generated from Leonardo A100
benchmark runs. CSV files preserve the plotted values, and SVG files provide the
corresponding figures. Large intermediate `points.json` and `fit.json` files are
generated by Benchscribe and are intentionally not tracked.

| Benchmark | Artifacts |
| --- | --- |
| `pingpong` | [`data/microbenchmarks/pingpong/figures`](data/microbenchmarks/pingpong/figures/) |
| `halo_1d` | [`data/microbenchmarks/halo_1d/figures`](data/microbenchmarks/halo_1d/figures/) |
| `allreduce` | [`data/microbenchmarks/allreduce/figures`](data/microbenchmarks/allreduce/figures/) |
| `alltoall` | [`data/microbenchmarks/alltoall/figures`](data/microbenchmarks/alltoall/figures/) |
| `cg_step` | [`data/application_benchmark/cg_step/figures`](data/application_benchmark/cg_step/figures/) |

The allreduce and all-to-all artifacts include successful
`sycl_oneccl_oshmpi` measurements from `1n2g` through `8n4g`.

Regenerate artifacts from a result tree with:

```bash
python3 tools/benchscribe results --format json > points.json
python3 tools/benchscribe results --fit --format json > fit.json
uv run --project tools/plot gpu-bench-plot \
  --points points.json --fit fit.json --figure all --outdir figures
```
